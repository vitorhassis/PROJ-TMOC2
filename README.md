# <h1 align="center">🎬 PROJ-TMOC2 🎬</h1>

<p align="center">
  🚀 Segundo projeto com o tema da série <strong>"Todo Mundo Odeia o Chris"</strong>, trazendo um <strong>Quiz interativo</strong> sobre os personagens.  
  Além disso, ao clicar em <strong>"Conheça melhor os personagens"</strong>, o usuário será redirecionado para um dos meus primeiros projetos,  
  onde desenvolvi uma Landing Page com informações detalhadas sobre cada personagem.

## 🛠 Funcionalidades  

✔️ Quiz interativo com **10 perguntas** sobre a série  
✔️ Perguntas com **diferentes níveis de dificuldade**  
✔️ Cálculo automático da pontuação e exibição do resultado  
✔️ Redirecionamento para uma **Landing Page** com informações sobre os personagens  

---

## 🚀 Tecnologias utilizadas  

- ✅ **HTML5** - Estruturação da página  
- ✅ **CSS3** - Estilização e layout responsivo  
- ✅ **JavaScript** - Lógica do Quiz e manipulação do DOM
